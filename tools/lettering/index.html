AI 排版助手

离线编辑可直接使用；AI 连接正在检查。

第一次使用：连接自己的 ChatGPT
  1. 安装 Python 3.9+ 和 官方 Codex CLI。
  2. 双击包内「连接自己的ChatGPT」，在官方页面登录自己的账号。也可在终端运行 codex login。
  3. 双击「启用AI助手」。看到上方绿色「AI 已连接」即可排版。

已有本机 Codex 登录可直接使用。此版本只接入 Codex / ChatGPT，不提供任意 API 服务商设置；每人使用自己的额度。示例方案无需联网即可查看、应用。

点击请求会发送当前画面的去元数据预览和文字，使用你的 ChatGPT/Codex 额度。这里先展示方案；主界面「一键 AI 排版」会直接初排，随时可撤销。
